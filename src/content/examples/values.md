لغة Go تحتوي على أنواع مختلفة من القيم بما في ذلك النصوص، الأعداد الصحيحة، الأعداد العشرية، والقيم المنطقية، وغيرها. إليك بعض الأمثلة الأساسية.

```go
package main

import "fmt"

func main() {
```

النصوص، والتي يمكن دمجها معاً باستخدام عامل الـ `+`.

```go
    fmt.Println("go" + "lang")
```

الأعداد الصحيحة والعشرية.

```go
    fmt.Println("1+1 =", 1+1)
    fmt.Println("7.0/3.0 =", 7.0/3.0)
```

القيم المنطقية، مع العوامل المنطقية كما هو متوقع.

```go
    fmt.Println(true && false)
    fmt.Println(true || false)
    fmt.Println(!true)
}
```

تشغيل البرنامج:

```sh
$ go run values.go
golang
1+1 = 2
7.0/3.0 = 2.3333333333333335
false
true
false
```
