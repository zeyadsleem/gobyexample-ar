تدعم لغة Go *الثوابت* (Constants) للحروف، النصوص، القيم المنطقية، والقيم العددية.

```go
package main

import (
    "fmt"
    "math"
)
```

`const` تقوم بالتصريح عن قيمة ثابتة.

```go
const s string = "constant"

func main() {
    fmt.Println(s)
```

يمكن أن تظهر عبارة `const` أيضاً داخل متن الدالة.

```go
    const n = 500000000
```

التعبيرات الثابتة تقوم بعمليات حسابية بدقة تعسفية.

```go
    const d = 3e20 / n
    fmt.Println(d)
```

الثابت العددي ليس له نوع حتى يتم إعطاؤه نوعاً، مثلاً عن طريق تحويل صريح.

```go
    fmt.Println(int64(d))
```

يمكن إعطاء الرقم نوعاً باستخدامه في سياق يتطلبه، مثل تعيين لمتغير أو استدعاء دالة. على سبيل المثال، هنا `math.Sin` تتوقع `float64`.

```go
    fmt.Println(math.Sin(n))
}
```

تشغيل البرنامج:

```sh
$ go run constant.go 
constant
6e+11
600000000000
-0.28470407323754404
```
