*القنوات* (Channels) هي الأنابيب التي تربط الـ goroutines المتوازية. يمكنك إرسال قيم إلى القنوات من goroutine واحد واستقبال تلك القيم في goroutine آخر.

```go
package main

import "fmt"

```

أنشئ قناة جديدة باستخدام `make(chan val-type)`. القنوات محددة بنوع القيم التي تنقلها.

```go
    messages := make(chan string)
```

*أرسل* قيمة إلى قناة باستخدام صيغة `channel <-`. هنا نرسل "ping" إلى قناة `messages` التي أنشأناها أعلاه، من goroutine جديد.

```go
    go func() { messages <- "ping" }()
```

صيغة `<-channel` *تستقبل* قيمة من القناة. هنا سنستقبل رسالة "ping" التي أرسلناها أعلاه ونطبعها.

```go
    msg := <-messages
    fmt.Println(msg)
}
```
