تدعم Go تنسيق وتحليل الوقت عبر تخطيطات تعتمد على الأنماط (pattern-based layouts).

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    p := fmt.Println
```

إليك مثال أساسي لتنسيق الوقت وفقاً لـ RFC3339، باستخدام ثابت التخطيط المقابل.

```go
    t := time.Now()
    p(t.Format(time.RFC3339))
```

تحليل الوقت يستخدم نفس قيم التخطيط كما في `Format`.

```go
    t1, e := time.Parse(
        time.RFC3339,
        "2012-11-01T22:08:41+00:00")
    p(t1)
```

تستخدم `Format` و `Parse` تخطيطات تعتمد على الأمثلة. عادةً ما ستستخدم ثابتاً من حزمة `time` لهذه التخطيطات، ولكن يمكنك أيضاً توفير تخطيطات مخصصة. يجب أن تستخدم التخطيطات الوقت المرجعي `Mon Jan 2 15:04:05 MST 2006` لإظهار النمط الذي يجب تنسيق/تحليل الوقت/النص المعطى به. يجب أن يكون وقت المثال تماماً كما هو موضح: سنة 2006، الساعة 15، يوم الاثنين، إلخ.

```go
    p(t.Format("3:04PM"))
    p(t.Format("Mon Jan _2 15:04:05 2006"))
    p(t.Format("2006-01-02T15:04:05.999999-07:00"))
    form := "3 04 PM"
    t2, e := time.Parse(form, "8 41 PM")
    p(t2)
```

للتمثيلات الرقمية البحتة، يمكنك أيضاً استخدام تنسيق النصوص القياسي مع المكونات المستخرجة من قيمة الوقت.

```go
    fmt.Printf("%d-%02d-%02dT%02d:%02d:%02d-00:00\n",
        t.Year(), t.Month(), t.Day(),
        t.Hour(), t.Minute(), t.Second())
```

ستعيد `Parse` خطأً عند وجود مدخلات غير صالحة توضح مشكلة التحليل.

```go
    ansic := "Mon Jan _2 15:04:05 2006"
    _, e = time.Parse(ansic, "8:41PM")
    p(e)
}
```
