المؤقتات (Timers) هي للحالات التي تريد فيها فعل شيء مرة واحدة في المستقبل - أما *المنبهات* (tickers) فهي للحالات التي تريد فيها فعل شيء بشكل متكرر في فترات زمنية منتظمة. إليك مثال على منبه يدق بشكل دوري حتى نقوم بإيقافه.

```go
package main

import (
    "fmt"
    "time"
)

func main() {
```

تستخدم المنبهات آلية مشابهة للمؤقتات: قناة يتم إرسال القيم عليها. هنا سنستخدم `select` على القناة لانتظار القيم فور وصولها كل 500 ملي ثانية.

```go
    ticker := time.NewTicker(500 * time.Millisecond)
    done := make(chan bool)

    go func() {
        for {
            select {
            case <-done:
                return
            case t := <-ticker.C:
                fmt.Println("دق المنبه عند", t)
            }
        }
    }()
```

يمكن إيقاف المنبهات مثل المؤقتات. بمجرد إيقاف المنبه لن يستقبل أي قيم إضافية على قناته. سنوقف منبهنا بعد 1600 ملي ثانية.

```go
    time.Sleep(1600 * time.Millisecond)
    ticker.Stop()
    done <- true
    fmt.Println("تم إيقاف المنبه")
}
```

تشغيل البرنامج:

```sh
$ go run tickers.go
دق المنبه عند 2012-09-23 11:29:56.487625 -0700 PDT
دق المنبه عند 2012-09-23 11:29:56.988063 -0700 PDT
دق المنبه عند 2012-09-23 11:29:57.488076 -0700 PDT
تم إيقاف المنبه
```
