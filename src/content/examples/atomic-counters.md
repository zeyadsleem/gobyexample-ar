الآلية الأساسية لإدارة الحالة في Go هي التواصل عبر القنوات. رأينا ذلك مثلاً مع أحواض العمال (worker pools). ومع ذلك، هناك خيارات أخرى لإدارة الحالة. هنا سننظر في استخدام حزمة `sync/atomic` لإنشاء *عدادات ذرية* (atomic counters) يتم الوصول إليها بواسطة عدة goroutines.

```go
package main

import (
    "fmt"
    "sync"
    "sync/atomic"
)

func main() {
```

سنستخدم نوعاً صحيحاً ذرياً لتمثيل عدادنا (دائماً موجب).

```go
    var ops atomic.Uint64
```

ستساعدنا `WaitGroup` في انتظار انتهاء جميع الـ goroutines من عملها.

```go
    var wg sync.WaitGroup
```

سنبدأ 50 goroutines تقوم كل منها بزيادة العداد 1000 مرة بالضبط.

```go
    for i := 0; i < 50; i++ {
        wg.Add(1)

        go func() {
            for j := 0; j < 1000; j++ {
```

لزيادة العداد بشكل ذري نستخدم `Add`.

```go
                ops.Add(1)
            }
            wg.Done()
        }()
    }
```

انتظر حتى تنتهي جميع الـ goroutines.

```go
    wg.Wait()
```

هنا لا توجد goroutines تكتب في `ops` ولكن باستخدام `Load` فمن الآمن قراءة القيمة ذرياً حتى أثناء قيام goroutines أخرى بتحديثها (ذرياً).

```go
    fmt.Println("ops:", ops.Load())
}
```
