في لغة Go، *المصفوفة* (Array) هي تسلسل مرقم من العناصر ذات طول محدد. في كود Go المعتاد، الشرائح (Slices) أكثر شيوعاً؛ المصفوفات مفيدة في بعض السيناريوهات الخاصة.

```go
package main

import "fmt"

func main() {
```

هنا نقوم بإنشاء مصفوفة `a` تتسع لـ 5 أعداد صحيحة (int) بالضبط. نوع العناصر والطول كلاهما جزء من نوع المصفوفة. افتراضياً، تكون المصفوفة ذات قيم صفرية، وهو ما يعني 0 للأعداد الصحيحة.

```go
    var a [5]int
    fmt.Println("emp:", a)
```

يمكننا تعيين قيمة عند فهرس معين باستخدام صيغة `array[index] = value` والحصول على قيمة باستخدام `array[index]`.

```go
    a[4] = 100
    fmt.Println("set:", a)
    fmt.Println("get:", a[4])
```

الدالة المضمنة `len` تعيد طول المصفوفة.

```go
    fmt.Println("len:", len(a))
```

استخدم هذه الصيغة للتصريح عن مصفوفة وتهيئتها في سطر واحد.

```go
    b := [5]int{1, 2, 3, 4, 5}
    fmt.Println("dcl:", b)
```

يمكنك أيضاً جعل المترجم يعد العناصر لك باستخدام `...`.

```go
    b = [...]int{1, 2, 3, 4, 5}
    fmt.Println("dcl:", b)
```

إذا حددت الفهرس مع `:`، فسيتم تصفير العناصر الموجودة بينها.

```go
    b = [...]int{100, 3: 400, 500}
    fmt.Println("idx:", b)
```

أنواع المصفوفات هي أحادية البعد، ولكن يمكنك تركيب الأنواع لبناء هياكل بيانات متعددة الأبعاد.

```go
    var twoD [2][3]int
    for i := range 2 {
        for j := range 3 {
            twoD[i][j] = i + j
        }
    }
    fmt.Println("2d: ", twoD)
```

يمكنك إنشاء وتهيئة المصفوفات متعددة الأبعاد دفعة واحدة أيضاً.

```go
    twoD = [2][3]int{
        {1, 2, 3},
        {1, 2, 3},
    }
    fmt.Println("2d: ", twoD)
}
```

لاحظ أن المصفوفات تظهر بصيغة `[v1 v2 v3 ...]` عند طباعتها باستخدام `fmt.Println`.

تشغيل البرنامج:

```sh
$ go run arrays.go

set: [0 0 0 0 100]

dcl: [1 2 3 4 5]

2d:  [[1 2 3] [1 2 3]]
```
