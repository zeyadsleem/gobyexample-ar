[*تحديد المعدل*](https://en.wikipedia.org/wiki/Rate_limiting) (Rate limiting) هو آلية مهمة للتحكم في استهلاك الموارد والحفاظ على جودة الخدمة. تدعم Go تحديد المعدل بأناقة باستخدام الـ goroutines والقنوات والمنبهات (tickers).

```go
package main

import (
    "fmt"
    "time"
)

func main() {
```

أولاً سننظر في تحديد المعدل الأساسي. لنفترض أننا نريد تحديد معالجتنا للطلبات الواردة. سنقوم بخدمة هذه الطلبات من قناة بنفس الاسم.

```go
    requests := make(chan int, 5)
    for i := 1; i <= 5; i++ {
        requests <- i
    }
    close(requests)
```

قناة `limiter` هذه ستستقبل قيمة كل 200 ملي ثانية. هذا هو المنظم في مخطط تحديد المعدل الخاص بنا.

```go
    limiter := time.Tick(200 * time.Millisecond)
```

من خلال الإعاقة عند الاستقبال من قناة `limiter` قبل خدمة كل طلب، فإننا نحدد أنفسنا بطلب واحد كل 200 ملي ثانية.

```go
    for req := range requests {
        <-limiter
        fmt.Println("الطلب", req, time.Now())
    }
```

قد نرغب في السماح بدفقات قصيرة (bursts) من الطلبات في مخطط تحديد المعدل مع الحفاظ على حد المعدل العام. يمكننا تحقيق ذلك من خلال تخزين قناة المحدد مؤقتاً. قناة `burstyLimiter` هذه ستسمح بدفقات تصل إلى 3 أحداث.

```go
    burstyLimiter := make(chan time.Time, 3)
```

املأ القناة لتمثيل الدفقات المسموح بها.

```go
    for i := 0; i < 3; i++ {
        burstyLimiter <- time.Now()
    }
```

كل 200 ملي ثانية سنحاول إضافة قيمة جديدة إلى `burstyLimiter` حتى حدها الأقصى وهو 3.

```go
    go func() {
        for t := range time.Tick(200 * time.Millisecond) {
            burstyLimiter <- t
        }
    }()
```

الآن لنحاكي 5 طلبات واردة أخرى. أول 3 منها ستستفيد من قدرة الدفق الخاصة بـ `burstyLimiter`.

```go
    burstyRequests := make(chan int, 5)
    for i := 1; i <= 5; i++ {
        burstyRequests <- i
    }
    close(burstyRequests)
    for req := range burstyRequests {
        <-burstyLimiter
        fmt.Println("الطلب", req, time.Now())
    }
}
```
