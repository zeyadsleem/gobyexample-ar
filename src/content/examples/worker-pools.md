في هذا المثال سنلقي نظرة على كيفية تنفيذ *حوض عمال* (worker pool) باستخدام الـ goroutines والقنوات.

```go
package main

import (
    "fmt"
    "time"
)
```

هذا هو العامل، والذي سنقوم بتشغيل عدة نسخ متوازية منه. سيستقبل هؤلاء العمال المهام على قناة `jobs` ويرسلون النتائج المقابلة على `results`. سنقوم بالانتظار ثانية واحدة لكل مهمة لمحاكاة مهمة مكلفة برمجياً.

```go
func worker(id int, jobs <-chan int, results chan<- int) {
    for j := range jobs {
        fmt.Println("العامل", id, "بدأ المهمة", j)
        time.Sleep(time.Second)
        fmt.Println("العامل", id, "أنهى المهمة", j)
        results <- j * 2
    }
}

func main() {
```

لكي نستخدم حوض العمال الخاص بنا، نحتاج لإرسال المهام لهم وجمع نتائجهم. نقوم بإنشاء قناتين لهذا الغرض.

```go
    const numJobs = 5
    jobs := make(chan int, numJobs)
    results := make(chan int, numJobs)
```

هذا يبدأ 3 عمال، والذين سيكونون معيقين في البداية لعدم وجود وظائف بعد.

```go
    for w := 1; w <= 3; w++ {
        go worker(w, jobs, results)
    }
```

هنا نرسل 5 `jobs` ثم نغلق تلك القناة للإشارة إلى أن هذا كل العمل الذي لدينا.

```go
    for j := 1; j <= numJobs; j++ {
        jobs <- j
    }
    close(jobs)
```

أخيراً نجمع كل نتائج العمل. هذا يضمن أيضاً أن الـ goroutines الخاصة بالعمال قد انتهت. هناك طريقة بديلة لانتظار عدة goroutines وهي استخدام 'WaitGroup'.

```go
    for a := 1; a <= numJobs; a++ {
        <-results
    }
}
```
